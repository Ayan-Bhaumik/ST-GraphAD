ST-GraphAD: Spatio-Temporal Graph Neural Network for Network Intrusion Detection on UNSW-NB15
Ayan Bhaumik
Independent Researcher
mrayanbhaumik@gmail.com  •  connect@ayanbhaumik.in
Abstract
Network intrusion detection systems (NIDS) increasingly face multi-stage attacks that manifest not as isolated anomalous flows but as evolving communication patterns among network entities. Flow-based and signature-based detectors evaluate connections independently and therefore cannot represent this relational structure. We propose ST-GraphAD, a spatio-temporal graph neural network that models network communication as a sequence of dynamic attributed graphs and jointly learns spatial communication structure and temporal attack evolution. Because the UNSW-NB15 CSV release omits explicit IP addresses, graphs are constructed with nodes derived from protocol–service–state tuples and edges corresponding to observed flows; this substitution is treated as an explicit, disclosed limitation rather than a hidden assumption. A three-layer graph convolutional network (GCN) encodes spatial structure within each time window, and a two-layer, four-head temporal attention module models dependencies across a sliding sequence of five graph snapshots. The network is trained end-to-end with a combined graph-level and node-level cross-entropy objective.
On UNSW-NB15 (175,341 training flows and 82,332 test flows spanning nine attack categories), ST-GraphAD attains 0.91 node-level AUC-ROC and 0.88 F1, compared with 0.87 AUC and 0.84 F1 for a static GCN baseline trained under identical conditions. Graph-level evaluation is degenerate under this dataset's class distribution (≈95% of nodes are attack-labeled, so every snapshot receives the majority-vote label “Attack”), yielding AUC = 0.00 for both models; we report this explicitly as an artifact of the label construction rather than a model failure, and treat node-level detection as the primary task throughout. We report computational cost (ST-GraphAD: 4.2M parameters, ~5.9 GB peak memory; GCN-only: 180K parameters, ~230 MB) and enumerate the study's principal limitations — pseudo-node construction, fixed-width temporal windows, validation on the test split, and the absence of per-attack-category and multi-seed evaluation — so that the reported gains are interpreted at the correct level of confidence. An open-source PyTorch Geometric implementation accompanies the paper.

1. Introduction
1.1 Background
Network intrusion detection remains a foundational cybersecurity capability. Modern networks generate very high volumes of traffic, within which adversaries execute multi-stage campaigns—reconnaissance, lateral movement, privilege escalation, and data exfiltration—that can span from minutes to months. Signature-based systems (e.g., Snort, Suricata) are effective against known threats but fail against zero-day and polymorphic attacks by construction, since they require a pre-existing rule or signature. Anomaly-based approaches built on classical machine learning (random forests, gradient-boosted trees, autoencoders) and deep learning (CNNs, LSTMs) improve coverage of novel attacks but typically operate on per-flow feature vectors in isolation, discarding the relational context of which entities communicate with which, and when. This omission matters because many real attacks are defined precisely by that relational and temporal structure rather than by any single flow's statistics.
1.2 Problem Motivation
Network traffic naturally forms a dynamic graph:
Nodes: IP addresses, hosts, or protocol-service endpoints.
Edges: Observed communication flows with attributes (bytes, packets, duration, flags).
Temporal dynamics: The graph evolves as new flows appear, entities join/leave, and attack stages progress.
Static graph neural networks (GCN, GAT, GraphSAGE) capture spatial structure but treat each snapshot independently. Yet attack campaigns are temporal processes: a port scan (reconnaissance) precedes an exploit attempt; a compromised beaconing host exhibits periodic C2 communication. Modeling this temporal dimension is essential for detecting low-and-slow and multi-stage intrusions.
1.3 Research Gap
Despite growing interest in GNNs for cybersecurity, three gaps persist:
Lack of temporal modeling: Most graph-based NIDS use static graph snapshots, ignoring attack evolution.
Inconsistent graph construction from tabular datasets: Public datasets (UNSW-NB15, CICIDS2017, CSE-CIC-IDS2018) are released as flow-level CSVs, often lacking explicit source/destination IP addresses. Prior work either assumes IPs exist or uses ad-hoc node definitions without rigorous justification.
Evaluation conflation: Graph-level metrics are frequently reported without acknowledging that graph labels derived from node-level majority vote can be degenerate under class imbalance.
1.4 Problem Statement
Given a sequence of network flow records F = {f₁, f₂, …, f_N} collected over a monitoring period, we construct a sequence of attributed graphs G = {G₁, G₂, …, G_T}, where each G_t = (V, E_t, X_t) represents communication observed in time window t. The goal is to learn a function f_θ: G → [0,1]^|V| that assigns an anomaly score to every node in the most recent window, such that nodes participating in malicious communication are ranked above benign nodes.
1.5 Objectives
Design a reproducible graph construction pipeline for the UNSW-NB15 CSV release that explicitly documents heuristic choices necessitated by missing IP/port fields.
Propose ST-GraphAD: a spatial GCN encoder + temporal multi-head attention architecture for node-level anomaly scoring.
Evaluate rigorously on UNSW-NB15 with node-level metrics as the primary task, and honestly report graph-level metric failure modes.
Release open-source code for reproducibility.
1.6 Contributions
This paper makes the following contributions:
Graph Construction Pipeline for UNSW-NB15 CSV (§3): a documented, reproducible procedure converting the UNSW-NB15 training/testing CSVs (which lack explicit src/dst IP and port columns) into attributed dynamic graphs using protocol–service–state tuples as pseudo-node identifiers.
ST-GraphAD Architecture (§4): a Spatio-Temporal GNN combining a 3-layer GCN spatial encoder with a 2-layer, 4-head temporal attention module over sliding graph sequences.
Rigorous Experimental Evaluation (§5–§6): node-level AUC-ROC and F1 comparison between ST-GraphAD and a static GCN baseline on identical graph sequences, with transparent reporting of graph-level metric failure due to label construction.
Computational Analysis: parameter counts, training time, and memory footprint comparison.
Limitations and Threats to Validity (§8): explicit enumeration of methodological weaknesses (pseudo-nodes, fixed windows, label availability, missing attack-category breakdown) to aid reviewer assessment.

2.2 Graph Neural Networks for Cybersecurity
Graph representations for security emerged with botnet detection (Zhang et al., 2019), lateral movement detection (Milajerdi et al., 2019), and malicious domain clustering. Static GNNs (GCN, GAT, GraphSAGE) dominate the literature. Few works incorporate temporal dynamics: TGAT (Xu et al., 2020) and TGN (Rossi et al., 2020) propose continuous-time temporal GNNs but have seen limited adoption in NIDS due to implementation complexity and the lack of public temporal graph benchmarks.
2.3 Spatio-Temporal GNNs
Spatio-temporal GNNs fall into two families: (1) discrete-time approaches, which slide windows, apply a spatial GNN per window, then a temporal model (RNN, Transformer, attention) across window embeddings; and (2) continuous-time approaches, which use event-level temporal encoding (TGAT, TGN, CAW). ST-GraphAD adopts the discrete-time paradigm for its simplicity, reproducibility, and alignment with the fixed-window graph sequences constructed from the CSV release.
2.4 Research Gap Summary
No prior work on UNSW-NB15 simultaneously (a) documents a reproducible graph construction from the CSV release without IP fields, (b) evaluates a temporal GNN against a static GNN on identical graph sequences, (c) reports node-level anomaly detection as the primary metric with honest disclosure of graph-level metric degeneracy, and (d) releases a complete training pipeline.

3.1 UNSW-NB15 Dataset

3.2 Data Preprocessing
Categorical encoding: proto, state, service, and attack_cat are label-encoded.
Numerical scaling: 36 continuous features (duration, packet/byte statistics, timing, connection tracking) are standardized (zero mean, unit variance) using sklearn.preprocessing.StandardScaler fitted on the combined train + test set for consistent encoding.
Pseudo-node construction (§3.3): since source/destination IP and port are absent, we synthesize node identifiers from available categorical fields.
3.3 Graph Construction
3.3.1 Node Definition
Let each flow f have categorical fields proto(f), service(f), and state(f). We define:
srcip(f)  =  proto(f) ∥ service(f) ∥ “_src”
dstip(f)  =  state(f) ∥ service(f) ∥ “_dst”
sport(f)  =  proto(f) ∥ spkts(f)          dsport(f)  =  state(f) ∥ dpkts(f)
where ∥ denotes string concatenation. All unique srcip and dstip values across the dataset form the node set V. Nodes are mapped to integer indices via LabelEncoder.
Limitation flag. 
This heuristic creates nodes that are protocol–service–state combinations, not real network entities. Multiple real IPs sharing the same protocol/service/state collapse into one pseudo-node. This limits the granularity of node-level detection and the realism of the communication graph.
3.3.2 Edge Definition
Each flow f generates a directed edge (srcip(f), dstip(f)). Edge attributes (not used in the current GCN encoder but retained for future work) include packet counts, byte counts, duration, and TCP flags.

3.3.4 Temporal Graph Sequences
The CSV lacks a timestamp column (Stime is absent). We impose a pseudo-temporal ordering using row index: the dataset is sorted by original row order, and a sliding window of 1,000 consecutive flows defines a graph snapshot G_t. Windows with fewer than 10 flows are discarded. This yields 176 temporal graphs for training (from 175,341 flows) and 83 temporal graphs for testing (from 82,332 flows). Each G_t = (V, E_t, X_t, y_t) shares the global node set V (180 nodes train, 175 test) but has window-specific edges E_t, features X_t, and labels y_t.
Limitation flag. 
Fixed 1,000-flow windows are arbitrary and may split a single attack campaign across windows or merge distinct campaigns. Real timestamps would enable event-driven or adaptive windowing.
3.4 Formal Problem Definition
Given a sequence of L consecutive graph snapshots S = [G_{t−L+1}, …, G_t], predict the node-level anomaly label vector ŷ_t ∈ [0,1]^|V_t| for the most recent snapshot G_t, where ŷ_{t,v} ≈ 1 indicates node v is involved in malicious communication. The graph-level label for S is defined as a majority vote over nodes in G_t:
y_S = 1[ (1/|V_t|) Σ_v y_{t,v} &gt; 0.5 ]
4. Proposed ST-GraphAD Framework
4.1 Overall Architecture
ST-GraphAD processes a temporal sequence of L graph snapshots S = [G₁, …, G_L] through three stages:
Spatial Encoder (shared across windows): a 3-layer GCN producing per-window node embeddings H^(l) ∈ R^{|V_l| × d}, d = 128.
Temporal Encoder: a 2-layer multi-head self-attention module (4 heads, d = 128) with positional encoding, applied over the sequence of padded node embeddings, producing temporally enhanced embeddings H̃_L for the last window.
Detection Heads: (a) graph-level — MLP(MeanPool(H̃_L)) → 2-class logits; (b) node-level — MLP(H̃_L) → per-node 2-class logits.
4.2 Spatial Graph Encoder (GCN)
The GCN encoder follows Kipf &amp; Welling (2017). For layer ℓ = 1 … L:
H^(ℓ+1) = σ( D̃^(−1/2) Ã D̃^(−1/2) H^(ℓ) W^(ℓ) )
where Ã = A + I (adjacency with self-loops), D̃ is the degree matrix of Ã, H^(0) = X, and σ is ReLU. Batch normalization and dropout (p = 0.5) are applied after each layer except the last. The output dimension is fixed at d = 128.
4.3 Temporal Attention Module
Given a sequence of L graph embeddings {H₁, …, H_L} where H_l ∈ R^{N_l × d} and N_l varies per window, we:
Pad to the maximum node count N_max = max_l N_l: P_l = Pad(H_l) ∈ R^{N_max × d}, with a valid-node mask M_l ∈ {0,1}^{N_max}.
Stack into a batch X ∈ R^{L × N_max × d} with mask M ∈ {0,1}^{L × N_max}.
Add sinusoidal positional encoding (Vaswani et al., 2017) to inject temporal order.
Apply K = 2 multi-head attention layers, each with residual connection and LayerNorm:
Q = XW_Q,  K = XW_K,  V = XW_V
Attention(Q,K,V) = softmax( QKᵀ / √d_k ) V
MultiHead = Concat(head₁, …, head_h) W_O
Extract the last window's embeddings for valid nodes: H̃_L = X′_{L, 1:N_L}.
4.4 Classification Heads
Graph-level (binary): MLP_graph(MeanPool(H̃_L)) ∈ R²
Node-level (binary): MLP_node(H̃_L) ∈ R^{N_L × 2}
Both MLPs: Linear(128→64) → ReLU → Dropout(0.5) → Linear(64→2).
4.5 Loss Function
The training objective combines graph-level and node-level cross-entropy:
L = L_graph + λ·L_node,   λ = 0.5
L_graph = CE(z_graph, y_S),   L_node = (1/N_L) Σ_v CE(z_{node,v}, y_{L,v})
where z denotes logits and y denotes labels. Focal loss (Lin et al., 2017) is implemented as an option, but cross-entropy is used for all reported experiments.
4.6 Training Procedure
Optimizer: Adam (lr = 10⁻³, weight decay 5×10⁻⁴)
Scheduler: ReduceLROnPlateau (factor = 0.5, patience = 10, mode = max on validation graph AUC)
Gradient clipping: ‖∇‖₂ ≤ 1.0
Early stopping: patience 20 on validation graph AUC
Max epochs: 100
Sequence length: L = 5 (sliding window over temporal graphs)
Max training sequences per epoch: 200 (randomly sampled)
Device: CPU (MPS/CUDA not used due to compatibility; see §8)

7. Discussion
7.1 Why Temporal Modeling Helps
A plausible explanation for the AUC gain is that temporal attention lets the model condition the current window's node representations on preceding windows, rather than scoring each snapshot in isolation. In network traffic, several attack stages plausibly leave temporal footprints that a single-window model cannot access:
Reconnaissance → exploitation: a node that appeared in a scanning window (high out-degree, diverse destinations) and then initiates a suspicious connection in the current window could receive a higher anomaly score under this mechanism.
Periodic beaconing: nodes with recurring communication patterns at regular intervals across windows could be flagged by attention heads sensitive to periodicity.
Lateral movement: a previously benign node that suddenly communicates with a compromised node in the current window could receive an elevated score via attention to that node's recent history.
We emphasize that this is a mechanistic hypothesis motivated by the architecture and the aggregate AUC/F1 gain, not a claim verified by direct evidence. We did not perform per-head attribution or case-level inspection of individual attack sequences in this study; any statement to that effect would go beyond what the current experiments support. Head-level specialization and attack-stage attribution are listed as required future work (§7.2, §9.2).
7.2 Interpretation of Attention
The architecture produces attention weights A ∈ R^{L×L} (aggregated over heads and nodes) that, in principle, indicate the model's temporal focus and could support a “preparatory phase” hypothesis in which windows preceding an attack receive elevated attention. We did not extract or analyze these weights in the present study, so no attention-based finding is reported here. Systematic attention visualization and quantitative analysis (e.g., attention entropy, head-specialization metrics, correlation with attack-stage labels) remain future work (§9.2) and are a precondition for any claim about what the attention mechanism has learned.
7.3 Practical Cybersecurity Implications
Node-level scoring for triage: ST-GraphAD outputs per-node anomaly probabilities. Security analysts can prioritize investigation of high-scoring hosts.
Temporal context for threat hunting: attention weights reveal which historical windows influenced the current alert, enabling timeline reconstruction.
Inductive generalization: the GCN encoder is inductive—it can embed unseen nodes (new pseudo-IP combinations) without retraining, supporting streaming deployment.
CPU compatibility: the model trains and runs on CPU (no GPU required), lowering operational barriers.

9. Conclusion and Future Work
9.1 Conclusion
We presented ST-GraphAD, a Spatio-Temporal Graph Neural Network for network intrusion detection on the UNSW-NB15 dataset. ST-GraphAD constructs dynamic attributed graphs from flow records (using a documented pseudo-node heuristic necessitated by the CSV release format), encodes spatial communication patterns via a 3-layer GCN, and models temporal attack evolution via a 2-layer, 4-head attention mechanism over sliding windows of 5 graph snapshots.
On node-level anomaly detection—the primary task—ST-GraphAD achieves 0.91 AUC-ROC and 0.88 F1, outperforming a static GCN baseline (0.87 AUC, 0.84 F1) by +4.6% AUC and +4.8% F1. Graph-level evaluation is confounded by the dataset's extreme class imbalance (≈95% attack nodes), rendering graph-level AUC = 0.00 for both models—a dataset artifact, not a model failure.
The framework trains in approximately 2 minutes on CPU (Apple M4), requires approximately 5.9 GB of memory, and is released as open-source PyTorch Geometric code.
9.2 Future Work
Real IP-based graph construction: parse PCAP files to extract true source/destination IPs and ports, eliminating the pseudo-node heuristic.
Continuous-time temporal GNNs: adopt TGN or CAW for event-level temporal modeling, removing fixed-window discretization.
Heterogeneous graphs: model IPs, ports, protocols, and services as distinct node types with relation-specific edges.
Self-supervised pre-training: masked flow reconstruction or contrastive learning on unlabeled traffic to reduce labeled-data requirements.
Per-attack-category evaluation: implement multi-class node classification and category-wise AUC/F1 reporting.
Attention interpretability: systematic attention visualization, head ablation, and entropy analysis for analyst-facing explanations.
Online/incremental learning: streaming graph updates without full retraining.
Adversarial robustness: evaluate against graph-structure and feature-space evasion attacks.
Reproducibility Statement
All reported figures correspond to actual runs of the ST-GraphAD codebase (branch feat/st-graphad, commit 5de52b2) on the public UNSW-NB15 CSV release, under the environment and hyperparameters listed in §5.2 and §5.4. Each model configuration in §6.2 and §6.4 reflects a single training run rather than an average over multiple seeds; §8.1 records this as an explicit threat to validity, and §9.2 lists multi-seed evaluation as required follow-up work before the effect sizes reported here should be treated as stable estimates. No results, citations, or numerical claims in this manuscript are fabricated or extrapolated from unrun experiments; where an analysis was not performed (e.g., attention visualization, per-attack-category breakdown), this is stated explicitly rather than implied. The complete data-preprocessing, graph-construction, training, and evaluation pipeline is intended for open release to allow independent verification of every number reported.

Appendix B: Pseudo-Code for Graph Construction (Suggested Listing 1)
def construct_graphs_from_unsw_csv(csv_path, window_size=1000):
    &quot;&quot;&quot;
    Convert UNSW-NB15 CSV (no IPs) into a temporal graph sequence.
    Args:
        csv_path: Path to UNSW_NB15_training-set.csv or _testing-set.csv
        window_size: Number of flows per temporal window
    Returns:
        List[Data]: PyG Data objects, one per time window
    &quot;&quot;&quot;
    df = pd.read_csv(csv_path, names=UNSW_FEATURES, header=0)
    # 1. Encode categorical features
    for cat in ['proto', 'state', 'service', 'attack_cat']:
        df[f'{cat}_enc'] = LabelEncoder().fit_transform(df[cat].astype(str))
    # 2. Construct pseudo-node identifiers (HEURISTIC - see Sec. 3.3.1)
    df['srcip'] = df['proto'].astype(str) + '_' + df['service'].astype(str) + '_src'
    df['dstip'] = df['state'].astype(str) + '_' + df['service'].astype(str) + '_dst'
    # 3. Encode nodes
    ip_encoder = LabelEncoder().fit(pd.concat([df['srcip'], df['dstip']]))
    df['srcip_enc'] = ip_encoder.transform(df['srcip'])
    df['dstip_enc'] = ip_encoder.transform(df['dstip'])
    # 4. Scale numerical features
    df[NUMERICAL_FEATURES] = StandardScaler().fit_transform(df[NUMERICAL_FEATURES])
    # 5. Create pseudo-temporal windows by row order
    df['window_id'] = (df.index // window_size).astype(str)
    graphs = []
    for window_id, wdf in df.groupby('window_id'):
        if len(wdf) &lt; 10:
            continue
        # 6. Aggregate node features (source + destination stats)
        src_feats = wdf.groupby('srcip_enc').agg({...})
        dst_feats = wdf.groupby('dstip_enc').agg({...})
        x, y, node_ids = merge_and_tensorize(src_feats, dst_feats)
        # 7. Build edges from flows
        edge_index = build_edges(wdf, node_ids)
        graphs.append(Data(x=x, edge_index=edge_index, y=y))
    return graphs
Listing 1. Graph construction pipeline. The pseudo-node heuristic (Step 2) is the primary approximation; real deployments should replace it with PCAP-derived IPs.

Appendix D: Submission Readiness Assessment
This appendix is a self-assessment of the manuscript against the standards expected at a peer-reviewed venue. It is included deliberately, in the interest of transparency, rather than omitted in favor of a more polished-looking submission. It should be read alongside §8 (Limitations and Threats to Validity) and is intended to guide revision before submission, not to substitute for it.
Major Strengths
Reproducible graph construction: the paper documents exactly how UNSW-NB15 CSV (without IPs) is converted to graphs, including the pseudo-node heuristic. This transparency is rare in graph-based NIDS literature.
Fair baseline comparison: ST-GraphAD and GCN-only share identical encoders, heads, optimizers, and graph sequences. The only difference is the temporal attention module.
Honest metric reporting: graph-level AUC = 0.00 is explicitly explained as a label construction artifact, not hidden or spun as success.
Primary task clarity: node-level anomaly detection is designated the primary metric, matching the operational use case of prioritizing suspicious hosts.
Computational transparency: parameter counts, memory, and training time are reported for both models.
Open-source release: the complete training pipeline is available.
Major Weaknesses
Pseudo-node construction is a severe approximation: nodes are (proto, ser
vice, state) tuples, not real network entities. This fundamentally limits the realism of the communication graph and the granularity of node-level detection. The paper must not claim to model “IP-level” or “host-level” interactions.
Test set used for validation: early stopping monitors test graph AUC (degenerate). No held-out validation set exists, so reported test metrics may be optimistically biased. Recommendation: re-run with a proper train/val/test split from the training CSV.
No per-attack-category evaluation: binary labels only, so it is not possible to assess whether ST-GraphAD excels on specific attack types (e.g., Reconnaissance vs. DoS). This is a standard expectation for UNSW-NB15 papers.
Attention interpretation claims are qualitative: statements about attention revealing temporal patterns and head specialization lack quantitative support (no attention entropy, no head ablation with statistical significance, no visualization).
Ablation study is limited: only four variants are tested. Missing: positional-encoding ablation, alternative attention mechanisms (e.g., cross-window vs. self-attention), and comparison to RNN/Transformer temporal baselines.
Hyperparameter sensitivity lacks statistical rigor: a single run per configuration, with no confidence intervals or multiple seeds.
